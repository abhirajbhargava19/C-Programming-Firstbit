# C Programming Assignments

A collection of C programming assignments and practice programs created during training at **FirstBit Solutions**.

## Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | Basic Concepts | Data types, variables, constants, I/O operations, compilation |
| 2 | Operators | Arithmetic, relational, logical, bitwise, conditional, increment/decrement |
| 3 | Conditional Statements | `if`, `if-else`, `switch-case`, nested conditions |
| 4 | Looping | `for`, `while`, `do-while`, nested loops, `break`, `continue` |
| 5 | Functions | All 4 types: with/without arguments × with/without return value |
